## 1. Gaussian Scale-Space Octave Generation Configurations

### 1.1 Continuous Scale-Space Representation
Given a 2D discrete luminance image $I(x, y) \in \mathbb{R}^{H \times W}$, the linear scale-space representation $L(x, y, \sigma)$ at spatial scale $\sigma > 0$ is generated by convolving $I(x, y)$ with a variable-scale 2D isotropic Gaussian kernel $G(x, y, \sigma)$:

$$L(x, y, \sigma) = G(x, y, \sigma) * I(x, y)$$

where the 2D Gaussian kernel is defined as:

$$G(x, y, \sigma) = \frac{1}{2\pi\sigma^2} \exp\left(-\frac{x^2 + y^2}{2\sigma^2}\right)$$

### 1.2 Separable 1D Convolution Decomposition
By algebraic separability of the isotropic 2D Gaussian distribution, the 2D convolution operator factors into two orthogonal 1D convolutions (horizontal pass along $x$, followed by vertical pass along $y$), reducing computational complexity per pixel from $\mathcal{O}(K^2)$ to $\mathcal{O}(2K)$ for kernel aperture $K = 2R + 1$:

$$G(x, y, \sigma) = g(x, \sigma) \cdot g(y, \sigma), \quad g(u, \sigma) = \frac{1}{\sqrt{2\pi}\sigma} \exp\left(-\frac{u^2}{2\sigma^2}\right)$$

For a discrete truncated kernel of radius $R = \lceil m \cdot \sigma \rceil$ ($u \in \{-R, \dots, R\}$), normalized discrete weights $\hat{g}[u]$ are constructed such that unit DC gain is preserved:

$$\hat{g}[u] = \frac{\exp\left(-\frac{u^2}{2\sigma^2}\right)}{\sum_{j=-R}^{R} \exp\left(-\frac{j^2}{2\sigma^2}\right)}, \quad \sum_{u=-R}^{R} \hat{g}[u] = 1$$

$$L_{\text{temp}}(x, y) = \sum_{u=-R}^{R} \hat{g}[u] \cdot I\left(\text{clamp}(x + u, 0, W-1),\, y\right)$$

$$L(x, y, \sigma) = \sum_{v=-R}^{R} \hat{g}[v] \cdot L_{\text{temp}}\left(x,\, \text{clamp}(y + v, 0, H-1)\right)$$

### 1.3 Octave & Intra-Octave Scale Quantization
Scale space is partitioned into $O$ discrete **octaves** indexed by $o \in \{0, 1, \dots, O - 1\}$. Each octave spans a factor-of-2 doubling in effective standard deviation $\sigma$:

1. **Multiplicative Scale Step Factor ($k$)**:
   Let $S$ denote the number of scale intervals per octave. Consecutive Gaussian smoothing levels within an octave are separated by a constant multiplicative factor $k$:
   $$k = 2^{1 / S}$$
2. **Intra-Octave Scale Schedule**:
   Given initial base smoothing $\sigma_0$ (e.g., $\sigma_0 = 1.6$ or $1.0$), the $i$-th Gaussian image within octave $o$ uses local smoothing parameter:
   $$\sigma_i = \sigma_0 \cdot k^i = \sigma_0 \cdot 2^{i / S}, \quad i \in \{0, 1, \dots, N_G - 1\}$$
   where $N_G = S + 1$ Gaussian images are required to produce $S$ Difference-of-Gaussians (DoG) slices per octave (or $N_G = S + 3$ when covering $S$ interior extremum-searchable DoG intervals).
3. **Effective Global Scale**:
   Accounting for octave spatial decimation $2^o$, the effective scale in original image coordinates is:
   $$\sigma_{\text{eff}}(o, i) = \sigma_0 \cdot 2^o \cdot k^i = \sigma_0 \cdot 2^{o + i/S}$$
4. **Incremental Semigroup Property**:
   By the Gaussian semigroup property $G(\sigma_a) * G(\sigma_b) = G\left(\sqrt{\sigma_a^2 + \sigma_b^2}\right)$, sequential blurring from scale $\sigma_{i-1}$ to $\sigma_i = k\sigma_{i-1}$ applies incremental blur:
   $$\Delta\sigma_i = \sqrt{\sigma_i^2 - \sigma_{i-1}^2} = \sigma_{i-1}\sqrt{k^2 - 1}$$

## 2. Structural Logic of the Difference-of-Gaussians (DoG) Downsampling Sequence

### 2.1 Difference-of-Gaussians (DoG) Band-Pass Formulation
Within each octave $o$, pairs of adjacent Gaussian scale-space slices $L^{(o)}(x, y, \sigma_i)$ and $L^{(o)}(x, y, \sigma_{i+1})$ (where $\sigma_{i+1} = k\sigma_i$) are subtracted element-wise to form the Difference-of-Gaussians response volume $D^{(o)}(x, y, \sigma_i)$:

$$D^{(o)}(x, y, \sigma_i) = \left(G(x, y, k\sigma_i) - G(x, y, \sigma_i)\right) * I^{(o)}(x, y) = L^{(o)}(x, y, k\sigma_i) - L^{(o)}(x, y, \sigma_i)$$

### 2.2 Equivalence to Scale-Normalized Laplacian of Gaussian ($\sigma^2 \nabla^2 G$)
By the heat diffusion equation $\frac{\partial G}{\partial \sigma} = \sigma \nabla^2 G$, the finite difference with respect to $\sigma$ satisfies:

$$\sigma \nabla^2 G = \frac{\partial G}{\partial \sigma} \approx \frac{G(x, y, k\sigma) - G(x, y, \sigma)}{k\sigma - \sigma} \implies D(x, y, \sigma) \approx (k - 1)\sigma^2 \nabla^2 G * I(x, y)$$

Because $(k - 1)$ is constant across all scales and octaves, the DoG operator inherently incorporates the required $\sigma^2$ scale normalization for true scale invariance without explicit second-derivative filtering.

### 2.3 Pyramidal Octave Downsampling Sequence
```
Octave o (Resolution: H_o x W_o, where H_o = H / 2^o, W_o = W / 2^o)
├── Gaussian Stack L^(o):
│   ├── L^(o)[0] = GaussianBlur(Base^(o), σ_0 * k^0)
│   ├── L^(o)[1] = GaussianBlur(Base^(o), σ_0 * k^1)
│   ├── ...
│   └── L^(o)[S] = GaussianBlur(Base^(o), σ_0 * k^S)
│
├── DoG Stack D^(o) (Element-wise Subtraction):
│   ├── D^(o)[0] = L^(o)[1] - L^(o)[0]
│   ├── D^(o)[1] = L^(o)[2] - L^(o)[1]
│   ├── ...
│   └── D^(o)[S-1] = L^(o)[S] - L^(o)[S-1]
│
└── Inter-Octave Spatial Decimation (2x Subsampling to Octave o + 1):
    └── Base^(o+1)(y, x) = Base_Smoothed^(o)(2y, 2x)
        for y in 0..(H_o / 2), x in 0..(W_o / 2)
```

Formally, the transition operator $\mathcal{T}_{\downarrow 2}: \mathbb{R}^{H_o \times W_o} \to \mathbb{R}^{\lfloor H_o/2 \rfloor \times \lfloor W_o/2 \rfloor}$ between octave $o$ and octave $o + 1$ subsamples every second pixel along both spatial axes after $2\sigma_0$ anti-aliased smoothing:

$$I^{(o+1)}(x, y) = L^{(o)}(2x, 2y, 2\sigma_0), \quad x \in \left[0, \lfloor W_o / 2 \rfloor - 1\right],\; y \in \left[0, \lfloor H_o / 2 \rfloor - 1\right]$$

This reduces the pixel count by a factor of $4$ at each subsequent octave, bounding the total multi-octave work by the geometric series $\sum_{o=0}^{O-1} 4^{-o} < \frac{4}{3}$ of the base octave cost.

## 3. 3D Neighborhood Pixel Comparison & Keypoint Localization Thresholds

### 3.1 26-Connected 3D Scale-Space Neighborhood ($\mathcal{N}_{26}$)
For each interior scale slice $s \in \{1, \dots, S - 2\}$ within an octave (where slices $s - 1$, $s$, and $s + 1$ share identical spatial dimensions $H_o \times W_o$) and each interior spatial coordinate $(x, y) \in [1, W_o - 2] \times [1, H_o - 2]$, the candidate sample $v_0 = D^{(o)}(x, y, s)$ is evaluated against its $3 \times 3 \times 3$ discrete scale-space neighborhood:

$$\mathcal{N}_{26}(x, y, s) = \left\{ (x + \Delta x,\, y + \Delta y,\, s + \Delta s) \;\middle|\; \Delta x, \Delta y, \Delta s \in \{-1, 0, +1\},\; (\Delta x, \Delta y, \Delta s) \neq (0, 0, 0) \right\}$$

This decomposes into three $3 \times 3$ planar stencils:
- **Lower Scale Plane ($\Delta s = -1$)**: $9$ neighbors $D^{(o)}(x + \Delta x, y + \Delta y, s - 1)$ for $(\Delta x, \Delta y) \in \{-1, 0, +1\}^2$.
- **Current Scale Plane ($\Delta s = 0$)**: $8$ surrounding spatial neighbors $D^{(o)}(x + \Delta x, y + \Delta y, s)$ for $(\Delta x, \Delta y) \in \{-1, 0, +1\}^2 \setminus \{(0, 0)\}$.
- **Upper Scale Plane ($\Delta s = +1$)**: $9$ neighbors $D^{(o)}(x + \Delta x, y + \Delta y, s + 1)$ for $(\Delta x, \Delta y) \in \{-1, 0, +1\}^2$.

### 3.2 Thresholding & Extrema Decision Predicates
1. **Contrast Magnitude Pre-Filter Threshold ($\tau_{\text{contrast}}$)**:
   Low-contrast fluctuations caused by sensor noise are rejected prior to full neighborhood traversal:
   $$\left|D^{(o)}(x, y, s)\right| \ge \tau_{\text{contrast}}$$
   In normalized intensity coordinates $I(x, y) \in [0, 1]$, $\tau_{\text{contrast}} \in [0.01, 0.03]$ (or scaled proportionally to image dynamic range).
2. **Strict 3D Local Extremum Predicate**:
   A candidate pixel $(x, y, s)$ is classified as a scale-space extremum if and only if it is strictly greater than (local maximum) or strictly less than (local minimum) all $26$ neighbors:
   $$\text{IsLocalMax}(x, y, s) \iff \forall (x', y', s') \in \mathcal{N}_{26}(x, y, s):\; D^{(o)}(x, y, s) > D^{(o)}(x', y', s')$$
   $$\text{IsLocalMin}(x, y, s) \iff \forall (x', y', s') \in \mathcal{N}_{26}(x, y, s):\; D^{(o)}(x, y, s) < D^{(o)}(x', y', s')$$
3. **Principal Curvature / Edge Rejection Threshold (2D Hessian Ratio)**:
   Because the DoG operator exhibits strong responses along poorly localized step edges (where one principal curvature is large across the edge and the orthogonal principal curvature along the edge is near zero), the $2 \times 2$ spatial Hessian matrix $\mathbf{H}$ at $(x, y, s)$ is computed via central finite differences:
   $$\mathbf{H} = \begin{bmatrix} D_{xx} & D_{xy} \\ D_{xy} & D_{yy} \end{bmatrix}$$
   where:
   $$D_{xx} = D(x+1, y, s) - 2D(x, y, s) + D(x-1, y, s)$$
   $$D_{yy} = D(x, y+1, s) - 2D(x, y, s) + D(x, y-1, s)$$
   $$D_{xy} = \frac{1}{4}\left(D(x+1, y+1, s) - D(x-1, y+1, s) - D(x+1, y-1, s) + D(x-1, y-1, s)\right)$$
   Let $\alpha = \lambda_{\max}$ and $\beta = \lambda_{\min}$ be the eigenvalues of $\mathbf{H}$, and let $r = \alpha / \beta$ denote the eigenvalue ratio threshold (typically $r = 10$). Using trace and determinant invariants:
   $$\text{Tr}(\mathbf{H}) = D_{xx} + D_{yy} = \alpha + \beta, \quad \det(\mathbf{H}) = D_{xx}D_{yy} - (D_{xy})^2 = \alpha\beta$$
   Candidate keypoints are retained only if:
   $$\det(\mathbf{H}) > 0 \quad \text{and} \quad \frac{\left(\text{Tr}(\mathbf{H})\right)^2}{\det(\mathbf{H})} < \frac{(r + 1)^2}{r}$$

4. **3D Taylor Series Sub-Pixel & Sub-Scale Extremum Refinement**:
   Around each discrete 3D extremum $\mathbf{x} = (x, y, s)^T$, the continuous scale-space DoG function $D(\mathbf{x} + \delta\mathbf{x})$ is approximated by its second-order 3D Taylor expansion:
   $$D(\mathbf{x} + \delta\mathbf{x}) = D(\mathbf{x}) + \left(\frac{\partial D}{\partial \mathbf{x}}\right)^T \delta\mathbf{x} + \frac{1}{2}\delta\mathbf{x}^T \mathbf{H}_{3\times 3} \delta\mathbf{x}$$
   Setting the gradient with respect to $\delta\mathbf{x} = (\delta x, \delta y, \delta s)^T$ to zero yields the continuous sub-pixel / sub-scale offset $\hat{\mathbf{x}}$ and interpolated extremum response $D(\hat{\mathbf{x}})$:
   $$\hat{\mathbf{x}} = -\mathbf{H}_{3\times 3}^{-1} \frac{\partial D}{\partial \mathbf{x}}, \quad D(\hat{\mathbf{x}}) = D(\mathbf{x}) + \frac{1}{2}\left(\frac{\partial D}{\partial \mathbf{x}}\right)^T \hat{\mathbf{x}}$$
   Candidates with $|D(\hat{\mathbf{x}})| > \tau_{\text{contrast}}$ emit sub-pixel coordinates $(x + \delta x)\cdot 2^o$, $(y + \delta y)\cdot 2^o$, and continuous scale $\sigma_0 \cdot 2^o \cdot k^{s + \delta s}$.

### 3.3 Structural Decision Pipeline Block
```
FOR each octave o in 0..O:
  FOR each interior DoG slice s in 1..(S - 1):
    prev_slice = D^(o)[s - 1]
    curr_slice = D^(o)[s]
    next_slice = D^(o)[s + 1]
    FOR y in 1..(H_o - 1):
      FOR x in 1..(W_o - 1):
        val = curr_slice[y, x]
        IF |val| < τ_contrast:
          CONTINUE (short-circuit reject low contrast)
        IF val > 0:
          VERIFY val > all 8 neighbors in curr_slice[y±1, x±1]
          VERIFY val > all 9 neighbors in prev_slice[y±1, x±1]
          VERIFY val > all 9 neighbors in next_slice[y±1, x±1]
        ELSE:
          VERIFY val < all 8 neighbors in curr_slice[y±1, x±1]
          VERIFY val < all 9 neighbors in prev_slice[y±1, x±1]
          VERIFY val < all 9 neighbors in next_slice[y±1, x±1]
        IF extremum_verified AND passes_hessian_edge_check(curr_slice, x, y, r):
          (dx, dy, ds, interp_val) = refine_extremum_3d(prev_slice, curr_slice, next_slice, x, y)
          IF |interp_val| > τ_contrast:
            EMIT Keypoint {
              x: (x + dx) * 2^o,
              y: (y + dy) * 2^o,
              scale: σ_0 * 2^o * k^(s + ds),
              response: interp_val
            }
```

## 4. Canonical Orientation Assignment & 128-D SIFT Descriptor Construction

### 4.1 Scale-Consistent Gradient Magnitude & Orientation
For each localized keypoint at $(x_k, y_k, \sigma_k)$, the Gaussian-smoothed image $L(x, y, \sigma_k)$ closest to the keypoint scale is sampled to compute centered finite differences:

$$L_x(x, y) = L(x + 1, y) - L(x - 1, y), \quad L_y(x, y) = L(x, y + 1) - L(x, y - 1)$$

$$m(x, y) = \sqrt{L_x(x, y)^2 + L_y(x, y)^2}, \quad \theta(x, y) = \operatorname{atan2}\left(L_y(x, y),\, L_x(x, y)\right) \bmod 2\pi$$

### 4.2 36-Bin Dominant Orientation Histogram & 80% Secondary Peak Splitting
Within a circular window of radius $R_{\text{ori}} = \lceil 3 \cdot \sigma_{\text{ori}} \rceil$ where $\sigma_{\text{ori}} = 1.5 \sigma_k$, each sample contributes to one of $B_{\text{ori}} = 36$ angular bins ($\Delta\theta = 10^\circ = \frac{2\pi}{36}$ per bin) weighted by gradient magnitude and an isotropic Gaussian falloff:

$$w_{\text{ori}}(\Delta x, \Delta y) = m(x_k + \Delta x, y_k + \Delta y) \cdot \exp\left(-\frac{\Delta x^2 + \Delta y^2}{2 \sigma_{\text{ori}}^2}\right)$$

After circular smoothing $h'[b] = \frac{1}{3}\left(h[(b-1)\bmod 36] + h[b] + h[(b+1)\bmod 36]\right)$, let $h'_{\max} = \max_b h'[b]$ denote the global peak height. Any local maximum bin $b^*$ satisfying the **secondary orientation splitting predicate**

$$h'[b^*] > h'[(b^* - 1) \bmod 36] \;\land\; h'[b^*] \ge h'[(b^* + 1) \bmod 36] \;\land\; h'[b^*] \ge 0.80 \cdot h'_{\max}$$

is refined via 3-point parabolic interpolation to emit a distinct `SiftFeature` orientation $\theta_k \in [0, 2\pi)$ at the same keypoint coordinate and scale:

$$\delta b = \frac{1}{2} \frac{h'[b^* - 1] - h'[b^* + 1]}{h'[b^* - 1] - 2h'[b^*] + h'[b^* + 1]}, \quad \theta_k = \left(b^* + 0.5 + \delta b\right) \frac{2\pi}{36} \bmod 2\pi$$

### 4.3 Rotation-Aligned $4 \times 4 \times 8 = 128$-Element Descriptor
To achieve rotation invariance, local sample offsets $(\Delta x, \Delta y)$ around $(x_k, y_k)$ are rotated by $-\theta_k$ into the keypoint's canonical frame and normalized by the subregion spacing $s_{\text{grid}} = 3 \sigma_k$:

$$\begin{bmatrix} u \\ v \end{bmatrix} = \frac{1}{s_{\text{grid}}} \begin{bmatrix} \cos\theta_k & \sin\theta_k \\ -\sin\theta_k & \cos\theta_k \end{bmatrix} \begin{bmatrix} \Delta x \\ \Delta y \end{bmatrix}, \quad \theta_{\text{rel}} = \left(\theta(x, y) - \theta_k\right) \bmod 2\pi$$

- **Spatial Subregions**: $4 \times 4$ grid of cells $(r_{\text{cell}}, c_{\text{cell}}) \in \{0, 1, 2, 3\}^2$.
- **Orientation Bins per Subregion**: $8$ bins ($45^\circ$ per bin).
- **Descriptor Dimension**: $4 \times 4 \times 8 = 128$ scalar components $\mathbf{d} \in \mathbb{R}^{128}_{\ge 0}$.
- **Illumination Invariance (Normalize $\to$ Clamp $\to$ Re-normalize)**:
  1. First $L_2$ normalization: $\hat{\mathbf{d}} = \mathbf{d} / \|\mathbf{d}\|_2$ (cancels linear contrast/gain changes).
  2. Saturation clamping: $\tilde{d}_i = \min(\hat{d}_i, 0.2)$ for $i \in \{0, \dots, 127\}$ (suppresses non-linear specular/lighting spikes).
  3. Final $L_2$ re-normalization: $\mathbf{d}_{\text{final}} = \tilde{\mathbf{d}} / \|\tilde{\mathbf{d}}\|_2$.

## 5. Nearest-Neighbor Ratio Matching & Tracking Layer

Given a query feature set $\mathcal{F}^Q = \{(\mathbf{p}_i^Q, \sigma_i^Q, \theta_i^Q, \mathbf{d}_i^Q)\}$ and a target feature set $\mathcal{F}^T = \{(\mathbf{p}_j^T, \sigma_j^T, \theta_j^T, \mathbf{d}_j^T)\}$:

1. **Euclidean Descriptor Distance**:
   $$d(\mathbf{d}_i^Q, \mathbf{d}_j^T) = \left\|\mathbf{d}_i^Q - \mathbf{d}_j^T\right\|_2 = \sqrt{\sum_{m=0}^{127} \left(d_{i,m}^Q - d_{j,m}^T\right)^2}$$
2. **Lowe's Ambiguity Ratio Test**:
   Let $j_1$ be the nearest neighbor in $\mathcal{F}^T$ with distance $d_1$, and $j_2 \neq j_1$ be the second-nearest neighbor with distance $d_2 \ge d_1$. The correspondence $(i, j_1)$ is accepted if and only if:
   $$\frac{d_1}{d_2} < \tau_{\text{ratio}} \quad (\text{default } \tau_{\text{ratio}} = 0.75)$$
3. **Inter-Frame Kinematics / Tracking Summary**:
   Across all accepted matches $\mathcal{M}$, aggregate frame-to-frame motion estimates:
   $$\Delta\bar{\mathbf{p}} = \frac{1}{|\mathcal{M}|}\sum_{(i,j)\in\mathcal{M}} (\mathbf{p}_j^T - \mathbf{p}_i^Q), \quad \bar{s} = \frac{1}{|\mathcal{M}|}\sum_{(i,j)\in\mathcal{M}} \frac{\sigma_j^T}{\sigma_i^Q}, \quad \Delta\bar{\theta} = \operatorname{atan2}\left(\sum \sin(\theta_j^T - \theta_i^Q),\, \sum \cos(\theta_j^T - \theta_i^Q)\right)$$
